# 🚗 Used Car Price Analysis

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on a used car dataset to understand the factors affecting car selling prices.

## 🎯 Objectives
- Analyze used car prices.
- Clean and preprocess the dataset.
- Identify missing values and duplicates.
- Detect outliers using the IQR method.
- Understand relationships between car features and selling prices.
- Generate business insights using data visualization.

##  Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
1. Data Loading and Inspection
2. Data Cleaning
3. Missing Value Analysis
4. Duplicate Detection
5. Descriptive Statistics
6. Outlier Detection
7. Univariate Analysis
8. Bivariate Analysis
9. Correlation Analysis
10. Business Insights
